# Página web - Static-Club
Tienda en línea de vinilos para descubrir, comprar y coleccionar música en todos los formatos.

Este proyecto es desarrollado para crear una tienda en línea de vinilos. Con el fin de crear una tienda en línea de vinilos que permita a los usuarios explorar, comprar y coleccionar discos de distintos géneros y artistas.
